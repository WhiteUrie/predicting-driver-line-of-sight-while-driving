============================================================
1. CÁC FILE GỬI KÈM
============================================================

Nội dung gồm các file sau:

3. results_demo.zip
   - Chứa kết quả chạy thử của mô hình.

============================================================
2. YÊU CẦU MÔI TRƯỜNG
============================================================

Hệ điều hành khuyến nghị:
- Ubuntu Linux

Ngôn ngữ và thư viện:
- Python 3.10
- PyTorch
- Torchvision
- OpenCV
- NumPy
- SciPy
- tqdm
- Pillow
- einops
- timm
- matplotlib
- ffmpeg

GPU khuyến nghị:
- NVIDIA GPU có hỗ trợ CUDA.
- Trong đồ án, em chạy trên GPU NVIDIA GTX 1650 Max-Q.

Tạo môi trường conda:

conda create -n salmamba python=3.10 -y
conda activate salmamba

Cài đặt thư viện cần thiết:

pip install torch torchvision torchaudio
pip install opencv-python numpy scipy tqdm pillow einops timm matplotlib

Cài ffmpeg để ghép ảnh thành video:

sudo apt update
sudo apt install ffmpeg -y

Kiểm tra GPU:

python -c "import torch; print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"

Nếu kết quả trả về True và hiện tên GPU thì môi trường đã nhận GPU.

============================================================
5. CHẠY HUẤN LUYỆN MÔ HÌNH
============================================================

Di chuyển vào thư mục source code:

cd /home/hauvo/SaliencyMamba

Kích hoạt môi trường:

conda activate salmamba

5.1. Huấn luyện trên TrafficGaze

python train.py \
    --category TrafficGaze \
    --root /home/hauvo/SaliencyMamba/dataset/TrafficGaze/Traffic_Gaze \
    --batch-size 12 \
    --num_workers 8 \
    --max_iters 49080 \
    --epochs 30 \
    --gpu 0

Nếu muốn train tiếp từ checkpoint cũ:

python train.py \
    --category TrafficGaze \
    --root /home/hauvo/SaliencyMamba/dataset/TrafficGaze/Traffic_Gaze \
    --batch-size 12 \
    --num_workers 8 \
    --max_iters 49080 \
    --epochs 30 \
    --gpu 0 \
    --resume ckpts/TrafficGaze/salmm_20260413-16:08:19/model_epoch_2.tar

5.2. Huấn luyện trên DrFixD-rainy

python train.py \
    --category DrFixD_rainy \
    --root /home/hauvo/SaliencyMamba/dataset/DrFixD_rainy/DrFixD-rainy \
    --batch-size 12 \
    --num_workers 8 \
    --max_iters 52291 \
    --epochs 30 \
    --gpu 0

Kết quả sau khi train:
- Trọng số mô hình sẽ được lưu trong thư mục ckpts/.
- Mỗi lần train sẽ tạo một thư mục checkpoint riêng, ví dụ:
  ckpts/TrafficGaze/salmm_20260414-12:48:59/
  ckpts/DrFixD_rainy/salmm_20260520-21:49:34/

============================================================
6. CHẠY ĐÁNH GIÁ MÔ HÌNH
============================================================

Mục đích:
Đánh giá mô hình bằng các chỉ số định lượng được trình bày trong báo cáo.

Các chỉ số sử dụng:
- CC: đo mức tương quan giữa bản đồ saliency dự đoán và ground truth.
- SIM: đo độ tương đồng giữa bản đồ saliency dự đoán và ground truth.
- KLD: đo độ sai khác phân phối giữa dự đoán và ground truth.

Lệnh đánh giá trên TrafficGaze:

python evaluation.py \
    --network salmm \
    --b 1 \
    --g 0 \
    --category TrafficGaze \
    --root /home/hauvo/SaliencyMamba/dataset/TrafficGaze/Traffic_Gaze \
    --test_weight salmm_20260414-12:48:59

Lệnh đánh giá trên DrFixD-rainy:

python evaluation.py \
    --network salmm \
    --b 1 \
    --g 0 \
    --category DrFixD_rainy \
    --root /home/hauvo/SaliencyMamba/dataset/DrFixD_rainy/DrFixD-rainy \
    --test_weight salmm_20260520-21:49:34

Kết quả mong đợi:
Chương trình sẽ in ra các chỉ số đánh giá như CC, SIM và KLD. Các chỉ số này được dùng để lập bảng kết quả trong báo cáo đồ án.

Lưu ý:
Nếu trong source code file đánh giá không tên là evaluation.py mà tên là test.py hoặc eval.py thì thay evaluation.py bằng đúng tên file trong project.

============================================================
8. GHÉP ẢNH KẾT QUẢ THÀNH VIDEO
============================================================

Sau khi chạy visualization.py, nếu trong thư mục temp có các ảnh dạng:

add_frame_000001.png
add_frame_000002.png
add_frame_000003.png
...

thì có thể ghép thành video bằng ffmpeg.

Di chuyển vào thư mục chứa ảnh:

cd /home/hauvo/SaliencyMamba/visualResults/test_thucte_DrfixD_rainy/video7/temp

Chạy lệnh:

ffmpeg -framerate 20 \
    -i add_frame_%06d.png \
    -c:v libx264 \
    -pix_fmt yuv420p \
    result_video.mp4

Kết quả:
- File result_video.mp4 được tạo trong cùng thư mục.
- Đây là video demo kết quả trực quan hóa dùng để đưa vào thư mục results_demo.zip.

Lưu ý:
Nếu tên ảnh không đúng dạng add_frame_%06d.png thì cần sửa lệnh cho đúng với tên ảnh thực tế.

Ví dụ nếu ảnh có dạng frame_000001.png thì dùng:

ffmpeg -framerate 20 \
    -i frame_%06d.png \
    -c:v libx264 \
    -pix_fmt yuv420p \
    result_video.mp4

============================================================
13. MỘT SỐ LỖI THƯỜNG GẶP VÀ CÁCH XỬ LÝ
============================================================

Lỗi 1: torch.cuda.is_available() trả về False

Nguyên nhân:
- Máy chưa nhận GPU.
- Driver NVIDIA hoặc CUDA chưa phù hợp.
- Cài nhầm bản PyTorch CPU.

Cách xử lý:
- Kiểm tra driver NVIDIA bằng lệnh:
  nvidia-smi
- Cài lại PyTorch bản hỗ trợ CUDA.

------------------------------------------------------------

Lỗi 2: Không tìm thấy dataset

Ví dụ lỗi:
No such file or directory

Nguyên nhân:
- Sai đường dẫn --root.
- Dataset chưa được giải nén.
- Cấu trúc thư mục không đúng.

Cách xử lý:
- Kiểm tra lại đường dẫn dataset.
- Đảm bảo --root trỏ đúng vào thư mục dataset chính.

------------------------------------------------------------

Lỗi 3: Không tạo được video bằng ffmpeg

Ví dụ lỗi:
Could find no file with path 'add_frame_%06d.png'

Nguyên nhân:
- Tên ảnh không đúng định dạng add_frame_000001.png.
- Đang đứng sai thư mục.
- Ảnh không bắt đầu từ số 000001.

Cách xử lý:
- Dùng lệnh ls để kiểm tra tên ảnh:
  ls
- Nếu tên ảnh khác, sửa lại mẫu trong lệnh ffmpeg.
- Đảm bảo đang cd đúng vào thư mục chứa ảnh.

------------------------------------------------------------

Lỗi 4: CUDA out of memory

Nguyên nhân:
- Batch size quá lớn so với dung lượng GPU.

Cách xử lý:
- Giảm batch size.
Ví dụ:
  --batch-size 4
hoặc:
  --batch-size 2
